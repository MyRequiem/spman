=encoding utf8

=head1 NAME

spman - a powerful package manager for Slackware Linux

=head1 SYNOPSIS

spman <param> [param[, param ...]]

=head1 DESCRIPTION

Spman is a powerful Slackware package manager implemented in Python 3 and
 licensed under the MIT license.

Main features:
  - Check installed packages for upgrades
  - Download binary packages or source code from enabled repositories
  - Download, build, and install queued packages from the SBo repository
  - Remove or upgrade packages in the current directory
  - View the installation, update, and removal history of packages
  - Show a list of all dependencies for a package from the SBo repository
  - View the contents of files inside a SlackBuild archive from the SBo repository
  - Search for packages across all enabled repositories and view their info
  - Show a complete list of packages available in a repository
  - Scan for dependency issues in system packages using sbbdep or ldd
  - Search for broken links to nonexistent files or directories in a specified path
  - Check the health of installed system packages
  - Search for *.new configuration files on the system
  - Support command autocompletion

Supported repositories:

  Slackware (slack)
      http://ftp.osuosl.org/.2/slackware/

  SlackBuilds.org (sbo)
      http://slackbuilds.org/slackbuilds/

  Alien Bob (alienbob)
      http://bear.alienbase.nl/mirrors/people/alien/sbrepos/

  Multilib (multilib)
      http://bear.alienbase.nl/mirrors/people/alien/multilib/

=head1 OPTIONS

B<-h>, B<--help>
    Print the help message and exit.

B<-v>, B<--check-version>
    Check the program version for available updates.

B<-l>, B<--repolist>
    Print a list of all repositories configured in /etc/spman/repo-list.
    Unavailable repositories are highlighted in red.

B<-r>, B<--repoinfo>
    Show detailed information about all active repositories:
      - Name
      - URL
      - Date of the last update
      - Number of packages in the repository
      - Total compressed packages size
      - Total uncompressed packages size

B<-b>, B<--blacklist>
    Show blacklisted packages from /etc/spman/blacklist.

B<-u>, B<--update>
    Update local metadata for all repositories. The paths to the log files and
    package lists are specified in /etc/spman/spman.conf.
    By default:
        /var/log/spman/repo_name/ChangeLog.txt
        /var/lib/spman/repo_name/PACKAGES.TXT (or SLACKBUILDS.TXT)

        where repo_name is slack, sbo, alienbob, or multilib.

    NOTE:
        You must run 'spman --update' immediately after installing spman and
        configuring /etc/spman/spman.conf.

B<-t>, B<--health>
    Check the health of all installed system packages and display detailed
    information:
      - Total packages
      - Number of broken packages
      - Number of checked files
      - Number of missing files
      - Overall health percentage (%)

B<-w>, B<--new-config>
    Search for *.new configuration files on the system.

B<-g>, B<--check-upgrade>
    Check all installed packages for available upgrades.

B<-d>, B<--download> --pkg|--src <reponame> <pkg>[ <pkg> ...]
    Download binary packages or source code from a specified repository. Binary
    packages will be saved to the directory specified in the BUILD_PATH
    parameter of /etc/spman/spman.conf (default: /root/spman/build/). Source
    code and build scripts will be downloaded to the BUILD_PATH/pkg_name/
    directory.

    NOTE:
        Only '--pkg' is allowed for the 'multilib' repository.
        Only '--src' is allowed for the 'sbo' repository.

    Examples:
        Download the flashplayer-plugin package from the alienbob repository:
            $ spman --download --pkg alienbob flashplayer-plugin
            $ ls -1 /root/spman/build/
              flashplayer-plugin-30.0.0.134-x86_64-1alien.txz

        Download emacs and kdelibs source code along with their SlackBuild
        scripts from the standard Slackware repository:
            $ spman --download --src slack emacs kdelibs
            $ ls -1 /root/spman/build/
              emacs/
              kdelibs/

B<-m>, B<--upgrade-pkgs> [--only-new]
    Install or upgrade packages found in the current directory.

    --only-new
      Packages already installed on the system with the exact same name,
      version, build number, and tag will not be reinstalled.

B<-e>, B<--remove-pkgs>
    Remove packages from the system if corresponding *.t?z files in the current
    directory are already installed.

B<-q>, B<--queue> --add|--remove|--clear|--show|--install
    Download, build, and install queued packages from SlackBuilds.org (sbo).

    --add <pkg>[ <pkg> ...]    - Add package(s) to the queue
    --remove <pkg>[ <pkg> ...] - Remove package(s) from the queue
    --clear                    - Clear the queue
    --show                     - Print the queue contents
    --install                  - Download, build, and install queued packages

B<-y>, B<--history> [--update]
    View the package installation, update, and removal history.

    --update
      Update the installed packages database (reset history).

B<-p>, B<--find-deps> <pkg>
    Show a list of all dependencies for a package from the SlackBuilds.org
    (sbo) repository. Packages already installed in the system are highlighted
    in green.

B<-s>, B<--view-slackbuild> <pkg>
    View the contents of files included in a SlackBuild archive using a pager
    (e.g., README, doinst.sh, patches, slack-desc, .SlackBuild, .info).

B<-f>, B<--find-pkg> [--strict] <pattern>
    Search for a package (case-insensitive) across all enabled repositories and
    view its information.

    --strict
      Perform a strict exact-match search by package name.

B<-i>, B<--pkglist> <reponame> [--only-installed]
    Show a complete list of packages available in a repository. Packages
    already installed in the system are highlighted in green.

    --only-installed
      Show only installed packages.

B<-k>, B<--check-deps> --sbbdep|--ldd
    Search for dependency issues in the system packages.

    --sbbdep    - Use the 'sbbdep' tool
    --ldd       - Use 'ldd'

B<-a>, B<--bad-links> <path_to_dir>
    Search for broken links to nonexistent files or directories in the
    specified path.

=head1 FILES

General configuration file:
    /etc/spman/spman.conf

List of repositories:
    /etc/spman/repo-list

List of blacklisted packages:
    /etc/spman/blacklist

Log files for each repository:
    /var/log/spman/<repo>/ChangeLog.txt

Lists of packages for each repository:
    /var/lib/spman/<repo>/PACKAGES.TXT (or SLACKBUILDS.TXT)

List of installed packages:
    /var/lib/spman/pkg-db
    (generated by the 'spman --history --update' command)
